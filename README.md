# emfls-creator

`emfls-creator` is the EMFLS Creator Workspace for people who plan, structure, produce, and review blog, YouTube, and social content before publishing. It focuses on practical creator workflows rather than generic text generation.

This project is an independent site in the EMFLS Network and is built with Astro and TypeScript.

## Development

```bash
npm install
npm run dev
npm run check
npm run build
```

The detailed strategy, topic boundaries, information architecture, design identity, launch requirements, and operating rules are defined by the `emfls-creator` Site Control Page and the repository documents, including `SITE_STRATEGY.md`, `DESIGN_SYSTEM.md`, `CONTENT_POLICY.md`, `LAUNCH_CHECKLIST.md`, `TASKS.md`, and `PROJECT_HISTORY.md`.
